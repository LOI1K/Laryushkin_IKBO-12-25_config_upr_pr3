# Ассемблер и интерпретатор учебной виртуальной машины

Практическая работа №3 по дисциплине
«Конфигурационное управление».

Вариант 11. РТУ МИРЭА, ИКБО-12-25.

## Описание

Проект реализует ассемблер и интерпретатор
для учебной виртуальной машины (УВМ).

Язык реализации — Python 3.
Формат исходных программ — YAML.

Работа выполняется в пять этапов.

## Этап 1. Промежуточное представление

Реализованы:

- Чтение исходной программы из YAML.
- Проверка названий команд и их полей.
- Проверка типов и диапазонов значений.
- Преобразование команд во внутреннее представление.
- Вывод полей команд в тестовом режиме.
- Обработка ошибок исходной программы.

## Язык ассемблера

Программа представляет собой YAML-список команд.

Каждая команда содержит поле `command` и операнды,
соответствующие спецификации варианта 11.

Поддерживаемые команды:

| Команда | Код A | Поля    | Назначение                   |
| ------- | ----- | ------- | ---------------------------- |
| LOAD    | 4     | B, C    | Загрузка константы в регистр |
| READ    | 6     | B, C, D | Чтение памяти со смещением   |
| STORE   | 3     | B, C    | Запись регистра в память     |
| AND     | 1     | B, C, D | Побитовое И                  |

### Пример программы

```yaml
- command: LOAD
  B: 26
  C: 16

- command: READ
  B: 20
  C: 24
  D: 46

- command: STORE
  B: 21
  C: 29

- command: AND
  B: 14
  C: 100
  D: 12
```

Поля команд должны содержать неотрицательные целые
числа, не превышающие размеры полей спецификации.

## Этап 2. Формирование машинного кода

Реализовано преобразование промежуточного представления
в двоичный машинный код.

Особенности:

- Кодирование четырёх инструкций УВМ.
- Упаковка полей с помощью битовых сдвигов.
- Порядок байтов little-endian.
- Сохранение программы в бинарный файл.
- Вывод количества ассемблированных команд.
- Вывод байтов в тестовом режиме.

Размеры команд:

- LOAD — 3 байта.
- READ — 3 байта.
- STORE — 2 байта.
- AND — 6 байт.

Результаты кодирования сверены с примерами
спецификации варианта 11.

### Пример запуска

```bash
./run.sh examples/spec_tests.yaml output/program.bin --test
```

После выполнения создаётся файл `output/program.bin`.

Для просмотра машинного кода:

```bash
xxd -g 1 output/program.bin
```

Тестовая программа содержит четыре команды
общим размером 14 байт.

## Этап 3. Интерпретатор и операции с памятью

Реализован интерпретатор машинного кода учебной
виртуальной машины.

### Возможности

- Декодирование бинарных команд.
- Выполнение инструкций LOAD, READ и STORE.
- Модель из 32 регистров.
- Раздельная память команд и данных.
- Память данных размером 65536 ячеек.
- Проверка допустимости адресов памяти.
- Вывод выбранного диапазона памяти в JSON.
- Тестирование копирования массива.

### Основные модули

- `src/decoder.py` — декодирование машинных команд.
- `src/virtual_machine.py` — регистры, память и выполнение.
- `src/interpreter.py` — интерфейс запуска интерпретатора.

### Выполнение программы

Сначала необходимо ассемблировать исходный YAML-файл:

```bash
./run.sh examples/copy_array.yaml output/copy.bin
```

Запуск интерпретатора:

```bash
python3 -m src.interpreter \
  output/copy.bin output/target.json \
  --start 200 --end 202
```

Параметры интерпретатора:

- `program` — путь к бинарному файлу.
- `dump` — путь к выходному JSON-файлу.
- `--start` — начальный адрес диапазона.
- `--end` — конечный адрес включительно.

### Пример копирования массива

Файл `examples/copy_array.yaml` содержит программу
копирования массива из трёх элементов.

Исходные адреса: 100–102.
Целевые адреса: 200–202.

Исходный массив: [7, 12, 25].
Результирующий массив: [7, 12, 25].

Программа содержит 19 машинных инструкций.

### Результат выполнения

Содержимое `output/target.json`:

```json
{
  "200": 7,
  "201": 12,
  "202": 25
}
```

## Этап 4. Арифметико-логическое устройство

Реализовано выполнение побитовой операции AND.

Команда AND использует следующие поля:

- A = 1 — код операции.
- B — адрес регистра со вторым операндом.
- C — адрес памяти с первым операндом.
- D — адрес регистра для результата.

Выполняемая операция:

registers[D] = memory[C] & registers[B]

### Тестовая программа

Файл `examples/and_test.yaml` содержит программу,
которая выполняет побитовое И над числами 12 и 10.

Результат сохраняется по адресу памяти 200.

### Запуск

Ассемблирование программы:

    ./run.sh examples/and_test.yaml output/and_test.bin --test

Выполнение программы:

    python3 -m src.interpreter \
      output/and_test.bin output/and_result.json \
      --start 200 --end 200

Просмотр результата:

    cat output/and_result.json

Ожидаемый результат:

    {
      "200": 8
    }

### Тестирование

Добавлены проверки выполнения AND и обработки
недопустимых адресов памяти.

Всего после четвёртого этапа: 33 автоматических теста.

## Структура проекта

- `src/assembler.py` — загрузка YAML и разбор команд.
- `src/main.py` — интерфейс командной строки.
- `tests/test_assembler.py` — автоматические тесты.
- `examples/spec_tests.yaml` — примеры из спецификации.
- `run.sh` — скрипт запуска программы.
- `.gitignore` — исключения для Git.

## Функции

- `load_program(path)` — чтение YAML-файла.
- `parse_instruction(raw)` — проверка отдельной команды.
- `translate(program)` — преобразование программы
  в список инструкций.
- `main()` — обработка аргументов и запуск ассемблера.
